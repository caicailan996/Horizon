### [Use pre-commit hooks to catch agents bypassing diagnostics libraries](https://simonwillison.net/2026/Oct/13/geoffrey-huntley/) ⭐️ 7.0/10

Geoffrey Huntley suggests adding a pre-commit hook that inspects the git diff for direct calls to observability modules that bypass his diagnostics library, failing the commit and injecting a prompt telling the agent to use the library. He contrasts this with only updating AGENTS.md, which can drift. The technique is described in his post “nobody should type code by hand anymore. here’s what’s left.”, quoted by Simon Willison.

rss · Simon Willison · Oct 13, 13:32

**「Background」** Pre-commit hooks are git hooks that run before a commit is accepted, and AGENTS.md files are commonly used to give coding agents project instructions. Huntley argues that relying on such documentation leaves a gap because agent behavior can drift. His proposal moves enforcement from documentation to the commit gate itself.

**「Impact」** Developers who adopt this hook no longer depend on agents following instructions: any diff that bypasses the required diagnostics library is rejected at commit time, and the agent receives a corrective prompt. This makes the diagnostics library an enforced part of the development workflow rather than a documented preference.
