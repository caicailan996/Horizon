### [Go 实验性平台无关 SIMD API 发布，性能提升约 5 倍](https://go.dev/blog/simd-experiment) ⭐️ 7.0/10

Go 官方博客宣布了一个实验性的、平台无关的 SIMD API，允许开发者在不同架构上编写统一的 SIMD 代码，无需使用特定平台的内建函数。实验性 API 支持非固定向量长度（如 ARM SVE 和 RISC-V 矢量扩展），社区基准测试显示便携 SIMD 代码相比非 SIMD 标量加速约 5 倍，虽然相比非便携架构 SIMD 慢约 11%。该 API 目前处于实验阶段，尚未稳定发布。

hackernews · yurivish · 9月25日 11:47 · [社区讨论](https://news.ycombinator.com/item?id=49843269)

**「背景」** Go 的标准库此前没有可移植的 SIMD 接口；需要向量化加速的程序通常要针对具体架构编写汇编，或通过 cgo 调用 C 代码，这会牺牲跨平台可移植性并增加维护成本。这个实验性 API 试图把 SIMD 操作纳入标准库，让同一份 Go 代码在不同 CPU 架构上获得向量化加速。

**「影响」** Go 开发者现在可以尝试在项目中引入平台无关的 SIMD 优化，跨 x86、ARM 和 RISC-V 等架构获得显著性能提升，同时保持代码可移植性。由于该 API 仍为实验性，生产环境使用需谨慎，但为编写无 C 依赖（CGO\_ENABLED=0）的高性能 Go 原生库创造了条件。

**「社区讨论」** 社区成员 ImJasonH 提供了一个在线基准测试，显示便携 SIMD 比非便携架构 SIMD 慢约 11%，但两者都比非 SIMD 代码快约 5 倍。mshockwave 指出该 API 是首个能更方便支持 SVE 和 RISC-V 矢量扩展等非固定向量长度的便携 SIMD 方案，不同于此前多数便携 SIMD 方案。
